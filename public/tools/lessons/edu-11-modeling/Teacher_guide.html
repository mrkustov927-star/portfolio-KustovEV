1. Цель и планируемые результаты

Цель: сформировать понимание полного цикла компьютерно-математического моделирования и анализа данных через исследование одной готовой модели с фиксацией измеримых результатов и ограничений.

Предметные: характеризовать пять этапов моделирования; различать прогнозирование, классификацию, кластеризацию и анализ отклонений; объяснять последовательность решения задач анализа данных; проводить компьютерный эксперимент и обосновывать вывод по графику и таблице.

Метапредметные (УУД): выдвигать проверяемую гипотезу; планировать опыт с изменением одной переменной; обнаруживать сомнительные данные; сопоставлять полученные результаты; работать в паре и аргументировать вывод; контролировать и оценивать собственные действия.

Личностные: ответственное отношение к достоверности выводов и ограничениям данных, понимание роли моделирования в науке и практике.

3. Практическая работа: алгоритм для ученика

  1. Выбрать модель (движение / популяция / экономика) и записать её цель.
  2. Сформулировать гипотезу: «Если увеличить/уменьшить …, то …».
  3. Записать исходные параметры и нажать «Запомнить опыт А».
  4. Изменить только один параметр; другие оставить постоянными.
  5. Сравнить текущую сплошную линию с пунктирной линией опыта А; зафиксировать два числовых результата.
  6. Сформулировать вывод: что поменялось, подтвердилась ли гипотеза, какие ограничения имеет модель.
  7. При необходимости скачать таблицу CSV или текст отчёта.

4. Математические модели и контрольные результаты

А. Движение с постоянным ускорением

До возможной остановки s(t) = v₀t + at²/2. При торможении (a < 0) скорость ограничена снизу нулём; после момента остановки путь не меняется. По умолчанию v₀ = 8 м/с, a = −0,8 м/с²: через 10 с s = 40 м, конечная скорость 0 м/с. Для сравнительного опыта увеличьте a до 0 м/с²: s = 80 м. Укажите, что это идеализированное одномерное движение с постоянным ускорением и без учёта сопротивления.

Б. Дискретный логистический рост популяции

Pₙ₊₁ = Pₙ + rPₙ(1 − Pₙ/K). По умолчанию P₀ = 60, r = 0,3 за шаг, K = 600. На шаге 15 прогноз около 546 особей; при увеличении r до 0,5 популяция быстрее приближается к K. Класс упрощённой модели: закрытая популяция, постоянная ёмкость среды, без случайных событий и возрастных групп. Число особей на графике может быть дробным, поскольку математическое значение является приближённой ожидаемой численностью; в таблице отображается округление.

В. Линейная модель спроса и прибыли

Q(p) = max(0, A − bp), Π(p) = (p − c)Q(p) − F, условно F = 120 ₽. По умолчанию A = 240, b = 5, c = 12, p = 28 ₽: Q = 100 штук, прибыль = 1480 ₽. При остальных фиксированных параметрах максимум на диапазоне p = 5…55 ₽ достигается при p = 30 ₽ и составляет 1500 ₽. Модель не учитывает конкурентов, ограничения запасов и вариативность спроса.

7. Управление сайтом

Откройте index.html в Chrome, Edge или Chromium. Для полноэкранного показа нажмите «⛶ Экран» или F11. Навигация: кнопки или стрелки, Page Up/Page Down, Home/End. Ctrl + колесо меняет масштаб именно презентации; есть кнопки − / 100% / +. «✎ Доска» включает прозрачный холст для стилуса. Кнопка «Все экраны» позволяет быстро перейти к любому этапу. «Заметки» показывает учителю подсказки к текущему экрану. Таймер отсчитывает время выбранного этапа.

Интернет не нужен: стили, формулы, графики и проверки встроены в один HTML-файл. CSV скачивается с десятичной запятой и разделителем «;» для удобства открытия в русскоязычных табличных редакторах.
