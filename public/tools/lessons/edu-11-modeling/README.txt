МОДЕЛЬ / ДАННЫЕ — интерактивная презентация-сайт для урока информатики, 11 класс

1. Откройте index.html в Google Chrome, Microsoft Edge или Chromium.
2. Для показа на проекторе нажмите «⛶ Экран» или F11.
3. Для перехода между слайдами используйте стрелки или кнопки «Назад» / «Далее».
4. Для масштабирования презентации удерживайте Ctrl и вращайте колесо мыши. Доступны также кнопки −, 100%, +.
5. Кнопка «Заметки» показывает подсказку учителю для текущего экрана.
6. Кнопка «Все экраны» позволяет быстро перейти к нужному этапу.
7. Кнопка «✎ Доска» включает рисование мышью/стилусом.
8. В лаборатории выберите модель, сохраните опыт А, измените один параметр и сравните графики.
9. Данные текущего эксперимента можно сохранить в CSV. Текст отчета можно сохранить в TXT.
10. Teacher_guide.html — технологическая карта и ключи для учителя. Student_worksheet.html — двухстраничный рабочий лист для печати.

Презентация автономная, доступ к интернету не нужен. Используются учебные математические модели, не реальные наблюдения.
Общая длительность урока — 40 минут, 14 экранов. Работа ориентирована на базовый уровень информатики 11 класса.
