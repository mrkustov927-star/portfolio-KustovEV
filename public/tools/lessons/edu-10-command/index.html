Как открыть в Windows

Win+R→cmd→Enter

Откроется командный интерпретатор cmd.exe.

Для нашего занятия достаточно обычного запуска.

    Реальная CMD

    На экране 2 покажите запуск CMD. Основная практика идёт в браузерной модели: она не обращается к файлам компьютера. Для переноса навыка можно открыть CMD в заранее подготовленной папке с plan.txt и повторить пример.

    Работаем именно в CMD: команды и параметры PowerShell могут отличаться. Права администратора для обычных операций в пользовательской папке не нужны.

    Как устроен тренажёр

    Это ограниченная учебная модель. Поддержаны основные формы dir, cd, mkdir, copy, type, cls, help. Форматы вывода упрощены. Удаление и системные команды в занятие не включены.
