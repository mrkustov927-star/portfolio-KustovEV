Excel: формулы, ссылки и диаграммы

11 класс · два урока по 40 минут. Материалы: автономный сайт, исходная книга ученика, пошаговая инструкция. Примеры и данные составлены специально для урока.

Первые две присланные подборки (283, 282) относятся к родственным связям в базе данных. Они вынесены в дополнительный блок и не входят в основные 80 минут. Остальные пять подборок определяют основной набор приёмов. На портале они отмечены как Д3/Д7; это не нумерация текущих заданий экзамена.

Проверяемые результаты обучения

  • Ученик различает значение ячейки и формулу, задаёт диапазон.
  • Применяет СУММ, СРЗНАЧ, МАКС; восстанавливает сумму по среднему и числу числовых ячеек.
  • Находит смещение при копировании, изменяет только относительные части ссылок.
  • Переводит условие диаграммы в отношения между значениями.
  • Проверяет расчёт изменением исходных данных и контролирует единицы.

До урока

Распакуйте архив. Откройте Excel_lab_11_offline.html в браузере. На компьютеры учеников выдайте Excel_practice_11.xlsx и Student_worksheet.html. Ключи оставьте у себя. Весь комплект, скачиваемый с сайта, включает руководство учителю: это учебный ресурс для тренировки, не защищённая контрольная.

Сайт имеет экраны 16:9; навигация стрелками клавиатуры, кнопками и меню. «Перо» включает доску поверх экрана; чтобы снова работать с ползунками, выключите перо. Рисунки сохраняются между экранами только в текущем сеансе. Таймер: щелчок — пуск/пауза, правая кнопка — сброс на 40 минут. Ответы сайта сохраняются в этом браузере при доступном localStorage; выгрузка результатов — текстовый файл. Для нового ученика используйте кнопку очистки с возможностью сначала скачать результаты.

Точные ключи к теории

  • Среднее 7 для четырёх чисел и D1=10: сумма A1:C1 = 18. Индивидуальные значения не определяются однозначно.
  • D3 → E2: смещение +1 столбец, −1 строка; =$B3+C$2 → =$B2+D$2 = 52.
  • В обратном копировании значение 16 находится в E3.
  • Три равных сектора: C1=6; A2=B2=C2=4.
  • Выручка: 175 тыс. руб.; результат 70 000 руб.
  • Ошибка резерва: =D2*(1+$H$2). Для одного копирования вниз H$2 также корректно.
  • Выходная проверка: 9; $C5; 40.

Проверка пересчёта

  • Резерв H2=20% → E8=21 360. Вернуть 10%.
