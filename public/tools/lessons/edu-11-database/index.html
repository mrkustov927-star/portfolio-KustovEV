Новое понятие

Что такое база данных?

База данных (БД) — организованная совокупность данных о предметной области, предназначенная для хранения, поиска и обработки.

🗃️

Хранит

Например, сведения об учениках, кружках и их посещении.

🔎

Помогает находить

Например, всех учеников конкретного кружка.

🔄

Позволяет изменять

Например, добавить ученика или исправить его класс.

Важен не сам факт хранения, а понятная структура данных, с которой удобно работать.

Почему база называется реляционной?

Реляционная база данных организует сведения в виде таблиц (отношений). Между таблицами можно устанавливать связи по общим значениям полей.

Таблица (отношение)

Состоит из столбцов (полей) и строк (записей). В реляционной базе данных данные организованы в таблицах; между ними могут быть связи.

Поле описывает характеристику объекта. Запись содержит сведения об одном экземпляре объекта.

Что здесь не так?

Один ученик может заниматься в нескольких кружках, а один кружок объединяет много учеников.

Имена, классы и руководители повторяются. При изменениях придётся исправлять множество строк — можно получить противоречивые данные.

Имя может повторяться

Двух разных учеников могут звать одинаково. А вот уникальный ID позволяет найти каждого без путаницы.

✅ Надёжнее ID: 101 и 104 обозначают разные записи даже при совпадении имён.

Первичный ключ (PK)

Поле или набор полей, значение которого уникально для каждой записи и не может быть пустым.

ФИО неудобно как ключ: могут встретиться полные тёзки.

Внешний ключ (FK)

Поле, которое ссылается на ключ другой таблицы.

В таблице «Записи» ID ученика указывает на строку таблицы «Ученики», а ID кружка — на строку «Кружки».

Шаг 5 · проверка целостности

Можно ли добавить такую запись?

🛡️

Ссылочная целостность

Если внешний ключ заполнен, он должен указывать на существующую запись в связанной таблице. В нашем примере оба внешних ключа обязательны.

Ученики: 101, 102, 103Кружки: 10, 20, 30

ID ученика = 999, ID кружка = 10

Пример · связываем таблицы в запросе

Как получить имена вместо ID?

Запрос объединяет данные

SELECT u.ФИО, k.Название FROM Записи AS z JOIN Ученики AS u ON z.ID_ученика = u.ID_ученика JOIN Кружки AS k ON z.ID_кружка = k.ID_кружка;

JOIN объединяет строки таблиц по значениям ключей.
