Вспоминаем

Магистрально‑модульный принцип

Компьютер состоит из отдельных функциональных модулей, которые взаимодействуют через общую магистраль.

Ключевое понятие

Что значит «модульный»?

🧩

Модули можно менять и добавлять

Например, установить больше оперативной памяти, заменить накопитель, подключить новое устройство.

🛣️

Магистраль связывает модули

По ней между устройствами передаются данные, адреса и управляющие сигналы.

Магистрально‑модульный принцип: компьютер строится из отдельных модулей, связанных общей системой обмена информацией.

Сравниваем

Системное или прикладное?

🧠

Системное ПО

Для чего? Чтобы работала компьютерная система.

С кем взаимодействует? С оборудованием, ОС и другими программами.

Примеры: ОС, драйверы, утилиты.

VS
🎯

Прикладное ПО

Для чего? Чтобы пользователь решил конкретную задачу.

С кем взаимодействует? С пользователем через возможности ОС.

Примеры: браузер, редактор, игра, навигатор.
