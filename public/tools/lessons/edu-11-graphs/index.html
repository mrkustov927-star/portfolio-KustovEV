Проблемный вход

Как описать сеть дорог?

Пять городов связаны дорогами. Для каждой дороги известно расстояние.
3 мин

Длинное описание

А соединён с Б и В. Б соединён с Г. В соединён с Г. Г соединён с Д. Расстояния различны.

Вопрос классу: «Как представить это так, чтобы структуру стало видно сразу?»
Используем граф: города → вершины, дороги → рёбра, расстояния → веса.
Не называйте «граф» сразу. Дайте детям предложить таблицу, карту, схему. Затем покажите, что граф делает связи видимыми.

Задание 13: считаем пути

Главное правило: число путей в вершину — сумма числа путей во все вершины, из которых в неё входят стрелки.
5 мин
Пометки ученика
N(X) = Σ N(предшественников)
А = 1
Б = А
В = А
Г = Б
Д = Б + В
Ж = Г + Д
Ответ:
На этом уроке достаточно одного базового типа. Остальные разновидности вынесены в режим «ЕГЭ» и не перегружают основную последовательность.

ЕГЭ · обязательная вершина

Пути должны проходить через Д

пути А→Д × пути Д→Ж

До Д: 2 пути.
После Д: 2 пути.

2 × 2 = 4
ЕГЭ · избегаемая вершина

Не проходить через Е

N(Е) = 0

Е не передаёт пути дальше.

Ж = 0 + 2 + 1 = 3
