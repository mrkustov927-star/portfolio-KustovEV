Миссия 01 · Главное понятие

Что такое компьютер?

Компьютер — универсальное электронное программно управляемое устройство для обработки данных.

🌍 Универсальный

Решает разные задачи.

📋 Программный

Работает по командам программ.

⚡ Электронный

Использует электронные компоненты.

🔢 Двоичный код

Обрабатывает данные как 0 и 1.

Устройство + программа = полезная работа

Миссия 03 · Мозг компьютера

Процессор — исполнитель команд

Процессор (CPU) — устройство, которое выполняет команды программ и обрабатывает данные.

🔢

Вычисляет

Складывает, сравнивает, принимает логические решения по программе.

🎮

Управляет

Координирует выполнение команд и обмен данными.

Я Бип! Представь: процессор — это исполнитель, который очень быстро выполняет инструкции.

Миссия 03 · Возможности CPU

Какие характеристики есть у процессора?

🧠

Количество ядер

Части процессора, способные выполнять команды.

⏱️

Тактовая частота

Число тактов за секунду, измеряется в ГГц.

🔢

Разрядность

Характеризует размер обрабатываемых данных и возможностей архитектуры.

Больше ГГц или ядер не всегда означает, что один процессор быстрее другого: важна вся его архитектура.
Миссия 04 · Хранители данных

Память хранит данные

Память компьютера — устройства для записи, хранения и выдачи данных.

Память бывает разной

Оперативная — для текущей работы. Долговременная — для сохранения файлов. Постоянная — для встроенных служебных программ.

Я Байт! Давайте разберёмся, почему файл можно хранить годами, а несохранённый текст исчезнет.
Миссия 04 · Оперативная память

ОЗУ — рабочий стол компьютера

⚡

Быстрое хранение

Данные и программы, с которыми процессор работает прямо сейчас.

🧩

Много задач

Открытые вкладки, редактор, игра используют оперативную память.

🔌

Зависит от питания

После выключения компьютера её содержимое теряется.

ОЗУ (RAM) — не место для постоянного хранения фотографий и документов.
Миссия 04 · Сохраняем надолго

SSD и HDD — шкаф для файлов

💽

SSD

Твердотельный накопитель. Хранит данные в микросхемах памяти.

🗄️

HDD

Жёсткий диск. Хранит данные на магнитных дисках.

🔑

Что хранится?

Операционная система, программы, фотографии и сохранённые файлы.

Данные на накопителе сохраняются и после выключения питания.

Миссия 04 · Виды внутренней памяти

ОЗУ, ПЗУ, кэш — не одно и то же

⚡

ОЗУ (RAM)

Временная память для работающих программ.

🔒

ПЗУ (ROM)

Энергонезависимая память со служебными данными и кодом устройства.

🚀

Кэш-память

Очень быстрая память рядом с процессором для часто нужных данных.

Простая аналогия: кэш — «под рукой», ОЗУ — «на рабочем столе», накопитель — «в шкафу».
