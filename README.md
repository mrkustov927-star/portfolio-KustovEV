# Портфолио Евгения Кустова

Практические разработки для Движения Первых, уроков информатики и творческих проектов: мастер-классы, карточки и игры, материалы для мероприятий, краеведческие маршруты и интерактивные сайты.

## Открыть сайт

Публичный адрес портфолио на GitHub Pages: [https://mrkustov927-star.github.io/portfolio-KustovEV/](https://mrkustov927-star.github.io/portfolio-KustovEV/)

Публикация выполняется через [GitHub Actions](.github/workflows/deploy-pages.yml): при обновлении ветки `main` собирается папка `public` и выкладывается на GitHub Pages. Для первоначального включения в настройках репозитория **Settings → Pages → Build and deployment → Source** нужно выбрать **GitHub Actions**.

## Что есть на сайте

- Каталог с поиском, фильтрами по теме и формату, подборками и избранным.
- Реальные снимки экранов сайтов и живые превью интерактивных инструментов.
- Просмотр комплектов изображений: открытие крупно, перелистывание и скачивание отдельных карточек.
- PDF для печати и доступные редактируемые исходники.
- Назначение, аудитория, авторство и роль участников в каждой карточке проекта.
- Карточки видны в HTML до запуска JavaScript.

В портфолио представлены «Азбука легенд родного края», «Орнаменты народов Карелии», «Носики Первых», закладки и открытки Кемского округа, «Техника Курской битвы», Школа актива, «Библиотеки и Движение Первых», материалы конференции, маршруты по Кеми, «Новости Первых» и ресурсы по первой помощи.

## Разработка с Codex

Прочитайте [AGENTS.md](AGENTS.md). Сайт не требует внешних JavaScript-библиотек и установки зависимостей.

```text
npm run build
npm run check
npm run dev
```

Для редактирования карточек меняйте `data/projects.json`, для разделов — `data/categories.json`, для структуры — `src/template.html`. Галереи находятся в `public/materials.js`; оптимизированные веб-копии — в `public/materials/`, учебные сайты — в `public/tools/lessons/`. Полные оригиналы и комплекты опубликованы в [GitHub Releases](https://github.com/mrkustov927-star/portfolio-KustovEV/releases/tag/portfolio-originals-2026-11-15).

Проект Vercel: `portfolio-kustovev` в команде KEV. Настройки сборки заданы в `vercel.json`.

## Источники и ограничения

Материалы импортированы из собственных разработок пользователя. Происхождение и исходные идентификаторы сохранены в `data/material-sources.json`; временные ссылки и реквизиты переноса не включены.

Изображения адаптированы для просмотра в браузере с сохранением пропорций. В просмотре доступны отдельные кнопки для оригинала и веб-копии. Все 3249 изображений и страниц связаны с исходными изображениями, PDF или архивами. Оригиналы доступны без входа в ChatGPT. Для страниц документа предлагается исходный PDF; его рендер не выдаётся за отдельный оригинал.

1984 исходных записи сохранены без изменения содержимого. Индивидуальные изображения из архивов и комплекты для скачивания опубликованы вместе с ними: всего 2237 файлов загрузки. Формат, объём, имя и SHA-256 записаны в `data/originals-manifest.json`. Для растровых оригиналов в галерее сохранены реальные размеры. Выборочная проверка скачивания PNG, PDF, ZIP, DOCX, PPTX, HTML, XLSX и MP4 без авторизации — в `data/download-verification.json`.

«Носики Первых», ежемесячные карточки и календарь представлены как архивные материалы. Текущую актуальность кампаний нельзя определять по старым карточкам. Демонстрационный барабан подарков использует условных участников.

Совместный проект маршрутов: Полина Боровкова и Матвей Шишкин; сопровождение — Евгений Кустов. «Новости Первых» — коллективная работа группы 7. Карточки без найденного исходного файла обозначены как описания.

Ориентиры оформления: [docs/design-references.md](docs/design-references.md).
