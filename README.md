# Портфолио Евгения Кустова

Практические разработки для Движения Первых: мастер-классы, карточки и игры, материалы для мероприятий, краеведческие маршруты и интерактивные сайты.

## Что есть на сайте

- Каталог с поиском, фильтрами по теме и формату, подборками и избранным.
- Реальные снимки экранов сайтов и живые превью интерактивных инструментов.
- Просмотр комплектов изображений: открытие крупно, перелистывание и скачивание отдельных карточек.
- PDF для печати и доступные редактируемые исходники.
- Назначение, аудитория, авторство и роль участников в каждой карточке проекта.
- Карточки видны в HTML до запуска JavaScript.

В портфолио представлены «Азбука легенд родного края», «Орнаменты народов Карелии», «Носики Первых», закладки и открытки Кемского округа, «Техника Курской битвы», Школа актива, «Библиотеки и Движение Первых», материалы конференции, маршруты по Кеми, «Новости Первых» и ресурсы по первой помощи.

## Разработка с Codex

Прочитайте [AGENTS.md](AGENTS.md). Сайт не требует внешних JavaScript-библиотек и установки зависимостей.

```text
npm run build
npm run check
npm run dev
```

Для редактирования карточек меняйте `data/projects.json`, для разделов — `data/categories.json`, для структуры — `src/template.html`. Галереи находятся в `public/materials.js`; оригинальные изображения и страницы — в `public/materials/`, файлы для скачивания — в `public/downloads/`.

Проект Vercel: `portfolio-kustovev` в команде KEV. Настройки сборки заданы в `vercel.json`.

## Источники и ограничения

Материалы импортированы из собственных разработок пользователя. Происхождение и исходные идентификаторы сохранены в `data/material-sources.json`; временные ссылки и реквизиты переноса не включены.

Изображения адаптированы для просмотра в браузере с сохранением пропорций. PDF и доступные редактируемые файлы сохранены отдельно. Для крупных исходных ZIP часть ссылок ведёт в ChatGPT и требует доступа к оригиналу; все импортированные изображения соответствующих комплектов доступны в галерее сайта.

«Носики Первых», ежемесячные карточки и календарь представлены как архивные материалы. Текущую актуальность кампаний нельзя определять по старым карточкам. Демонстрационный барабан подарков использует условных участников.

Совместный проект маршрутов: Полина Боровкова и Матвей Шишкин; сопровождение — Евгений Кустов. «Новости Первых» — коллективная работа группы 7. Карточки без найденного исходного файла обозначены как описания.

Ориентиры оформления: [docs/design-references.md](docs/design-references.md).
