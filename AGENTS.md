# Портфолио Евгения Кустова

Рабочий репозиторий сайта портфолио разработок для Движения Первых. Продолжать работу в этом репозитории; не создавать другой сайт или дубликат репозитория.

## Структура

- `data/projects.json` — карточки проектов, авторство, ссылки, темы и ключи галерей.
- `data/categories.json` — направления каталога.
- `src/template.html` — шаблон страницы.
- `public/app.js`, `public/styles.css` — интерфейс без внешних зависимостей.
- `public/materials.js` — фактический список импортированных карточек и страниц документов.
- `public/materials/`, `public/assets/`, `public/downloads/` — реальные файлы и превью.
- `data/material-sources.json` — происхождение импортированных материалов; без временных ссылок.
- `scripts/build.mjs` — создаёт статическую страницу с видимыми карточками до запуска JavaScript.

## Работа

1. Читай текущие файлы, сохраняя пользовательские правки.
2. Меняй исходные JSON и шаблон; выполни `npm run build` и `npm run check`.
3. Не придумывай ссылки, число участников, награды, авторов и результаты применения.
4. Совместный проект маршрутов: Полина Боровкова и Матвей Шишкин; сопровождение — Евгений Кустов. «Новости Первых» — коллективная работа группы 7.
5. На карточках сайтов используй реальные снимки экранов либо явно обозначенный живой просмотр. Не подменяй их вымышленными макетами.
6. Не публикуй ФИО детей из рабочих списков, контакты, заявления, договоры и другие служебные документы. В демонстрациях используй условных участников.
7. Внешность людей на исходных фотографиях, пропорции, возраст и индивидуальные черты сохраняй. Не изменяй внешность без прямого запроса.
8. Логотипы используй из оригинальных файлов с сохранением пропорций.
9. Карточки без исходника помечай как описание, а эскизы — как эскизы. Старые кампании и календари сохраняй с годом и месяцем.
10. Не сохраняй в репозитории токены, подписанные временные URL и служебные реквизиты переноса.
11. Не добавляй платные зависимости, аккаунты или системы авторизации для обычного каталога.

## Проверка

Проверь поиск, фильтры, открытие проекта, просмотр и перелистывание карточек, Escape, избранное, ссылки PDF и мобильную компоновку. Не утверждай, что проверка выполнена, если она не состоялась.

Размещение: проект Vercel `portfolio-kustovev`, команда KEV. Изменения основной ветки предназначены для этого портфолио.
