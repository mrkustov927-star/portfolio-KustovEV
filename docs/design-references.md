# Ориентиры оформления

Изучено 15 ноября 2026 года.

| Источник | Что полезно для этого портфолио |
|---|---|
| [Brittany Chiang](https://brittanychiang.com/) | Короткое представление автора, ясная навигация и проекты с пояснениями |

Выбран светлый каталог с крупными реальными превью, красным акцентом и карточками по практическим задачам. Внутри проекта — назначение, аудитория, авторство, изображения материалов и скачивание доступных файлов. Сложная 3D-навигация не нужна для поиска раздаточных материалов.

Референсы используются для выбора принципов подачи. Их тексты, иллюстрации и исходный код не копировались.
