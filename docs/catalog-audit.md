# Сверка каталога · 15 ноября 2026

В каталоге 75 разработок, 53 галереи, 605 изображений и страниц, 28 сайтов и интерактивных инструментов. После первичной сверки добавлена 21 разработка: 19 учебных комплектов по информатике и 2 проекта печатных материалов театра «Гротеск».

Просмотрены названия и метаданные 3 223 созданных файлов. Отобранные источники проверены по содержимому, визуальным листам и истории обсуждений. Это сверка доступного каталога, а не утверждение об абсолютной полноте всех чатов аккаунта. Версии объединены внутри соответствующих работ. Авторство партнёрских и коллективных проектов сохранено.

383 исходных файла подключены к публичному скачиванию без входа в ChatGPT. Вместе с отдельными изображениями из архивов и комплектами опубликовано 566 файлов загрузки. Содержимое оригиналов не изменено. Все 605 галерейных страниц связаны с исходным изображением, PDF или архивом. Перечень с размерами и контрольными суммами — в `data/originals-manifest.json`.

Сборка и проверка каталога выполнены. Для всех опубликованных файлов проверены размер и SHA-256 из GitHub API; для PNG, PDF, ZIP, DOCX, PPTX, HTML, XLSX и MP4 дополнительно проверено анонимное скачивание с сопоставлением контрольной суммы. Результат — в `data/download-verification.json`.

- авторская подборка конкурсных чек-листов;
- блокнот участника «Зарницы» на 60 страниц;

Для «Зарницы» сохранены 10 визуальных эскизов, для «Мостов Добра» — 3 макета. Они доступны отдельно и не подменяют отсутствующие файлы. Перечень восстановления — в `data/recovery-backlog.json`.

Личные фотосессии, служебные списки, документы с данными участников и чужие положения не выдаются за авторские разработки. Программы элективов и учебное планирование обозначены как рабочие версии. Архивные кампании сохраняют соответствующий статус.
